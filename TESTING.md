# Тесты

Тесты работают с настоящим PostgreSQL через HTTP-интерфейс FastAPI
внутри процесса. Сервер Uvicorn для этого запускать не нужно.
Перед тестами применяются миграции к отдельной тестовой базе.

```bash
python -m pip install -r requirements-dev.txt
docker compose -f docker-compose.test.yaml up -d --wait
python -m pytest -q
```

По умолчанию запускаются ровно пять итоговых тестов в
`tests/test_acceptance.py`. Каждый проверяет несколько вариантов из ТЗ.

Используется отдельная база `kvitto_test` на `localhost:55433`.
Контейнер хранит данные в памяти, без постоянного тома.
Тесты очищают платежи и тарифы только этой базы перед каждым сценарием.
Рабочий `.env` не изменяется.

При необходимости задайте `TEST_DATABASE_URL` с драйвером
`postgresql+asyncpg`. Имя базы обязано оканчиваться на `_test`;
другая база будет отклонена до запуска проверок.
Не запускайте набор параллельно в нескольких процессах против одной базы.

После проверки:

```bash
docker compose -f docker-compose.test.yaml down
```
